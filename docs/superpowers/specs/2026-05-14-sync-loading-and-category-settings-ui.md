# Sync Loading And Category Settings UI

## Goal

统一远端同步相关请求的 loading 体验，并将“新增一笔”页面里的“新增分类”入口改为设置图标，跳转到分类管理页。

## Confirmed Scope

- 所有远端同步相关请求都需要可见 loading
- 包括初始化拉取、自动同步、手动同步、账本加载/创建/切换、分类远端同步
- “新增一笔”页面不再支持表单内联新增分类
- 分类入口改为设置图标，点击进入分类管理页
- 进入分类管理页时需要带上当前收支类型，默认落在对应分类分组
- 从分类管理页返回后，新增一笔表单草稿保持不丢失，分类列表自动刷新

## UI Decisions

### 1. 远端 loading

- 保留现有手动按钮级禁用状态
- 增加统一的全局远端 loading 遮罩，覆盖所有远端同步相关请求
- 遮罩文案根据当前动作区分，例如：
  - 正在同步账本数据
  - 正在加载账本
  - 正在创建账本
  - 正在切换账本
  - 正在同步分类

### 2. 新增一笔页分类入口

- 在分类区域最后一个位置使用设置图标按钮
- 点击后跳转到 `/categories`
- 通过路由参数传递当前 `entryType`
- 删除交易表单中的分类内联输入区域和内联新增逻辑

## Implementation Notes

- 远端 loading 由 provider 统一管理，避免每个页面重复造状态
- 交易表单保留为共享组件，但分类管理入口改为显式回调
- 分类管理页在首次渲染时读取 `entryType` 路由参数设置默认分组
